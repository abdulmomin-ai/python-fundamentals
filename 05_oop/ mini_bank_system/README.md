# Overview

This is a simple Mini Bank System built using Python.
The project demonstrates the use of Object-Oriented Programming concepts such as Encapsulation and Abstraction along with File Handling.

The system allows users to create accounts, deposit money, withdraw money, and check account balances through a command-line interface.



## Concepts Used
- Classes and Objects
- Encapsulation (Private Variables)
- Abstraction (Abstract Base Classes)
- File Handling (Saving and Loading Accounts)
- Basic CLI Interaction



## Features
Create a new bank account
Deposit money into an account
Withdraw money from an account
Check account balance
Save account data to a file
Load accounts from file when program starts



## Project Structure

mini_bank_system
│

├── bank_system.py

├── accounts.txt

└── README.md



## How the System Works
The program starts and loads existing accounts from accounts.txt.
Users can create a new account with an initial balance.
Deposits and withdrawals update the account balance.
Account data is saved using file handling.



## How to Run the Project
Run the following command:
python bank_system.py
